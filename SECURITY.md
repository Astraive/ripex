# Security Policy

## Supported Versions

We support security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| 0.2.x   | :x:                |
| < 0.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it to the maintainers by opening a draft security advisory on GitHub or emailing `neerajcodz@gmail.com`. This address is also recorded in the security metadata in `Cargo.toml`.

We will acknowledge receipt within 48 hours and provide a timeline for coordination and release of a patch.
